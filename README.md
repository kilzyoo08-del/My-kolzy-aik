# My kolzy AI — Seedance UI prototype

Русский Android-проект на Kotlin + Jetpack Compose.

## Что уже есть
- Экран AI-видеостудии.
- Поле промпта для генерации.
- Режимы «Текст → видео» и «Фото → видео».
- Выбор исходного изображения.
- Длительность 5–15 секунд и формат 9:16 / 16:9 / 1:1.
- Экран честно показывает, что облачный генератор пока не подключён.

## Важно: почему генерация сейчас не запускается
Seedance 2.5 — облачная модель. APK не содержит саму модель и не может генерировать видео офлайн.
Для реальной генерации нужен API-ключ поставщика (например, Doitong) и сервер-посредник.
Ключ нельзя вшивать в APK: его можно извлечь из приложения. Сервер должен хранить ключ в переменной окружения и принимать запросы от приложения.

## Подключение генерации
После получения API-ключа нужно:
1. Развернуть небольшой backend с HTTPS.
2. Хранить `DOITONG_API_KEY` только в секретах backend.
3. Реализовать на backend создание задачи Seedance 2.5, проверку статуса и выдачу URL готового MP4.
4. В Android заменить обработчик кнопки «Сгенерировать видео» на запрос к своему backend.

Официальная документация Doitong указывает, что API-ключ передаётся в `Authorization: Bearer ...` и должен использоваться на сервере, а не в клиентском коде:
https://doitong.com/en-US/developers/models/bytedance/seedance-2.5/us/reference-to-video

## Сборка APK с телефона
Проект содержит GitHub Actions workflow `.github/workflows/build-apk.yml`.
Загрузите проект в свой GitHub-репозиторий, затем откройте вкладку Actions и запустите workflow. APK появится в Artifacts после успешной сборки.

## Ограничение этой версии
Это исходный проект интерфейса, не готовый APK и не подключённый генератор. Для сборки нужен Android Gradle build runner (например, GitHub Actions). Генерация потребует отдельного API-доступа и backend.
