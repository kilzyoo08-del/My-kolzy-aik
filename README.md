# Centerion — Android client

Android-приложение на Kotlin + Jetpack Compose. Клиент поддерживает автономный режим и подключение к собственному Centerion API.

## Текущее состояние

- Supabase Auth: регистрация, вход и обновление сессии.
- Access/refresh токены шифруются AES-GCM с ключом Android Keystore.
- API-клиент поддерживает историю диалогов, обратную связь и операции с документами памяти.
- Экран истории диалогов подключён.
- Экран «Память» подключён: поиск, сохранение и удаление личных заметок с подтверждением; есть состояния выполнения, ошибки и пустого результата.
- Сохранение заметки в память не меняет веса модели и не означает обучение.
- Чат API намеренно возвращает `model_unavailable`, пока к серверу не подключено реальное локальное ядро Centerion. Gemma не должна подменять Centerion в рабочем inference.

## Бесплатная архитектура

- В APK допускается только публичный Supabase publishable key.
- Не используются платные LLM API и не встраиваются серверные секреты.
- Будущее языковое ядро должно запускаться на открытых весах и отвечать собственными весами Centerion.
- Текущий API ещё не является готовым inference-сервисом; наличие маршрута чата не означает, что модель уже подключена.

## Параметры сборки

```bash
export CENTERION_SUPABASE_URL="https://tdqyhptkrmxoohfpfwvs.supabase.co"
export CENTERION_SUPABASE_PUBLISHABLE_KEY="sb_publishable_..."
gradle :app:assembleDebug
```

Можно передать те же значения через Gradle properties:
`-PCENTERION_SUPABASE_URL=...` и `-PCENTERION_SUPABASE_PUBLISHABLE_KEY=...`.

Для GitHub Actions добавьте repository variable `CENTERION_SUPABASE_PUBLISHABLE_KEY`. Это публичный ключ, а не секретный service-role key.

**Никогда не помещайте в APK** service-role credentials, пароли, приватные ключи или ключи платных API.

Если publishable key не задан, приложение остаётся в автономном режиме.

## Ограничения

- Фото не отправляется в облачную модель: визуальное распознавание пока не подключено.
- В автономном режиме доступны только локальные функции, которые явно реализованы в приложении.
- Чат через Centerion API заработает после подключения и проверки собственного runtime.
- Поиск в интернете не является частью собственного локального ядра Centerion.
- Сквозная изоляция данных ещё не подтверждена тестами с двумя реальными аккаунтами.

## Сборка

Открыть проект в Android Studio и выполнить `app:assembleDebug` либо запустить GitHub Actions workflow. Целевая платформа — Android 14 (targetSdk 34).
