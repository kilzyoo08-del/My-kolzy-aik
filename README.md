# My-kolzy AI — Android 14

Прототип приложения на Kotlin + Jetpack Compose.

## Что работает в этой версии
- Поле для идеи видео.
- Локальное улучшение промпта (без ChatGPT API).
- Копирование промпта в буфер обмена.
- Открытие публичного демо LTX-2.5 в браузере.
- Выбор желаемого формата и длительности как заметки для генерации.

## Генерация видео
Видео создаётся не внутри APK, а на публичном демо LTX-2.5 через Hugging Face: https://arpitkgoyal-ltx-2-5-demo.static.hf.space/index.html
Демо использует общую GPU-очередь, поэтому бесплатный доступ ограничен, возможны очереди, квоты и временные ошибки. После открытия страницы нужно вставить скопированный промпт, при необходимости загрузить изображение, настроить параметры и нажать Generate.

## Важно про ChatGPT
Встроенного ChatGPT в APK пока нет. Помощник в этой версии формирует расширенный промпт локально по шаблону. Для прямого доступа к ChatGPT из приложения нужен отдельный разрешённый способ интеграции; подписка ChatGPT не является API-доступом.

## Сборка
Открыть проект в Android Studio/совместимой среде Gradle и собрать APK. `targetSdk = 34` (Android 14).
