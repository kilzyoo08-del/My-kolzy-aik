# Сборка My kolzy AI APK только с телефона

1. Откройте https://github.com и войдите или создайте бесплатный аккаунт.
2. Создайте новый репозиторий с именем `My-kolzy-AI`. Для простоты можно выбрать Public; тогда стандартные GitHub-hosted Actions для публичного репозитория бесплатны. Если выбрать Private, действуют лимиты бесплатного тарифа.
3. Загрузите содержимое этой папки в корень репозитория (именно содержимое, включая скрытую папку `.github`). На телефоне в браузере GitHub можно использовать Add file → Upload files.
4. Откройте вкладку Actions. Если GitHub спросит, разрешите запуск workflows.
5. Выберите `Build My kolzy AI APK` → `Run workflow` → `Run workflow`.
6. Дождитесь зелёного статуса. Откройте завершённый запуск, найдите раздел Artifacts и скачайте `My-kolzy-AI-debug-apk`.
7. Распакуйте скачанный ZIP и установите APK. Android может попросить разрешить установку приложений из браузера/файлового менеджера.

Это debug APK для личной установки, не подписанный релиз для Google Play. Если сборка упадёт, откройте лог шага с ошибкой и пришлите его текст или скриншот.
