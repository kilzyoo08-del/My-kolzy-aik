My kolzy AI — файлы для Codemagic

ЧТО ДЕЛАТЬ:
1. Распакуй этот ZIP на телефоне.
2. Загрузи ВСЕ файлы и папки изнутри архива в корень GitHub-репозитория:
   https://github.com/kilzyoo08-del/My-kolzy-aik
   Важно: codemagic.yaml должен лежать рядом с settings.gradle.kts и build.gradle.kts.
3. Сохрани изменения в ветку main.
4. Вернись в Codemagic и нажми Check for configuration files.
5. Выбери workflow "My kolzy AI - Android APK" и запусти сборку.
6. После успешной сборки APK появится в Artifacts.

ВАЖНО:
- Это Android UI-прототип. Настоящая генерация видео внутри приложения пока не встроена.
- Приложение открывает внешний бесплатный демо-сервис LTX-2.5.
- Не загружай в репозиторий API-ключи, пароли и другие секреты.
- Загружай СОДЕРЖИМОЕ архива в корень репозитория, а не сам ZIP-файл.
