# Диалоговые данные KolzaiLM

Файл `instructions.jsonl` содержит примеры в формате JSONL:
- `instruction` — вопрос или инструкция пользователя;
- `input` — дополнительный контекст (может быть пустым);
- `output` — желаемый ответ.

Добавляй по одному JSON-объекту на строку. Проверяй точность ответов и права на материалы. Не добавляй персональные или секретные данные.

Подготовить текстовый корпус:

```powershell
python ml/kolzailm/prepare_data.py
```

Затем запустить обучение:

```powershell
python ml/kolzailm/train.py --data ml/kolzailm/data/train.txt --steps 3000
```

Важно: текущий train.py обучает обычное предсказание следующего байта на сериализованных диалогах. Это первый экспериментальный этап, а не полноценное instruction fine-tuning с маской потерь только на ответе. Маленький примерный набор не даст широких знаний и не научит модель отвечать на все вопросы. Для следующего этапа нужны большой проверенный корпус, отдельный validation-набор, метрики и специальный режим обучения на ответах.
