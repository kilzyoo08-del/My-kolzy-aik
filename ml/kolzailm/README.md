# Kolai — собственная языковая модель

Kolai — экспериментальная autoregressive Transformer-модель, которую мы обучаем **с нуля**: случайная инициализация весов, собственная byte-level токенизация UTF-8, собственный цикл обучения. Это не обёртка над готовой LLM. Текущий учебный корпус намеренно ограничен программированием: Python, Kotlin, Java и Roblox Luau.

## Первый этап

Первая версия намеренно маленькая:
- decoder-only Transformer с causal self-attention;
- токены — байты UTF-8 (256 значений + специальные BOS/EOS), поэтому русский текст поддерживается без готового токенизатора;
- обучается предсказывать следующий байт;
- данные — обычный текст, по одному примеру на строку в `data/train.txt`;
- контрольная выборка отделяется автоматически;
- чекпоинт сохраняет веса и конфигурацию.

Это учебный прототип, а не конкурент ChatGPT. На малом корпусе он будет генерировать слабый текст. Качество определяется прежде всего объёмом и качеством легально полученных данных и временем обучения.

## Запуск на Windows / CPU

Требуется Python 3.10+ и PyTorch. Установи подходящую сборку PyTorch с официального сайта https://pytorch.org/get-started/locally/ .

Из корня репозитория:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install torch
python ml/kolzailm/train.py --data ml/kolzailm/data/instructions.jsonl --steps 1000 --batch-size 4 --context 256
python ml/kolzailm/generate.py --checkpoint ml/kolzailm/checkpoints/kolai-instruct.pt --prompt "Привет! "
```

На CPU обучение будет медленным. Начни с небольшого корпуса и 300–1000 шагов, проверь, что процесс работает, затем увеличивай объём. Скрипт не требует CUDA. При наличии CUDA можно передать `--device cuda`.

## Формат данных

`data/instructions.jsonl` содержит учебные пары «вопрос по программированию — ответ с объяснением и кодом». Тренер читает JSONL напрямую; отдельная конвертация в `train.txt` для instruction-обучения не нужна.

Текущий тренер делает instruction fine-tuning: контекст вопроса подаётся модели, но функция потерь считается только по байтам ответа и завершающему EOS-токену. Слишком длинные примеры обрезаются до контекстного окна с сохранением конца ответа и наиболее свежей части вопроса. Это всё ещё маленькая byte-level модель, а не готовый помощник. Используй собственные примеры и материалы с подходящими лицензиями. Не добавляй пароли, личные данные и приватную переписку.

## Масштабирование корпуса

Не генерируй миллион случайных перефразировок: это создаёт дубликаты и ухудшает обобщение. Храни новые партии отдельными JSONL-файлами в UTF-8 и добавляй к записям метаданные происхождения, например `source`, `license`, `review_status` и `topic`. В `output` должен быть проверенный ответ, а не шаблон-заглушка.

Проверка и объединение подготовленных партий:

```powershell
python ml/kolzailm/build_dataset.py --input ml/kolzailm/data/instructions.jsonl ml/kolzailm/data/new_shards --output ml/kolzailm/data/instructions.clean.jsonl
```

Скрипт проверяет обязательные поля, пустые и слишком короткие ответы, JSON-синтаксис и повторяющиеся пары вопрос/ввод. Он **не доказывает фактическую правильность ответа** — код и объяснения нужно тестировать отдельно. Не включай в корпус данные без разрешённой лицензии, секреты или личную переписку.

Цель в 1 000 000 записей — долгосрочный ориентир, а не повод искусственно раздувать корпус. Следи за разнообразием задач, источниками, лицензиями, долей проверенных ответов и качеством на отдельном тестовом наборе.


### Партии задач с разбором решения

Новые проверяемые задачи добавляются отдельными файлами в `data/`, например `reasoning_shard_001.jsonl`. Примеры учат модель давать краткое обоснование: определить условия, выбрать метод, показать проверку результата и назвать ограничения. Это не обучение раскрытию скрытых внутренних рассуждений: Kolai должна выдавать полезное объяснение решения, а не длинный поток мыслей.

Собрать исходный корпус и новую партию без повторов:

```powershell
python ml/kolzailm/build_dataset.py --input ml/kolzailm/data/instructions.jsonl ml/kolzailm/data/reasoning_shard_001.jsonl --output ml/kolzailm/data/instructions.clean.jsonl
python ml/kolzailm/train.py --data ml/kolzailm/data/instructions.clean.jsonl --steps 1500 --batch-size 4 --context 256 --out ml/kolzailm/checkpoints/kolai-instruct.pt
```

Проверяй ответы на отдельном наборе задач, которые не включались в обучение. Низкая ошибка на обучающей выборке сама по себе не доказывает, что модель умеет решать новые задачи.
