# Kolai — собственная языковая модель

Kolai — экспериментальная autoregressive Transformer-модель, которую мы обучаем **с нуля**: случайная инициализация весов, собственная byte-level токенизация UTF-8, собственный цикл обучения. Это не обёртка над готовой LLM. Текущий учебный корпус намеренно ограничен программированием: Python, Kotlin, Java и Roblox Luau.

## Первый этап

Первая версия намеренно маленькая:
- decoder-only Transformer с causal self-attention;
- токены — байты UTF-8 (256 значений + специальные BOS/EOS), поэтому русский текст поддерживается без готового токенизатора;
- обучается предсказывать следующий байт;
- данные — обычный текст, по одному примеру на строку в `data/train.txt`;
- контрольная выборка отделяется автоматически;
- чекпоинт сохраняет веса и конфигурацию.

Это учебный прототип, а не конкурент ChatGPT. На малом корпусе он будет генерировать слабый текст. Качество определяется прежде всего объёмом и качеством легально полученных данных и временем обучения.

## Запуск на Windows / CPU

Требуется Python 3.10+ и PyTorch. Установи подходящую сборку PyTorch с официального сайта https://pytorch.org/get-started/locally/ .

Из корня репозитория:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install torch
python ml/kolzailm/train.py --data ml/kolzailm/data/train.txt --steps 3000
python ml/kolzailm/generate.py --checkpoint ml/kolzailm/checkpoints/kolzailm.pt --prompt "Привет! "
```

На CPU обучение будет медленным. Начни с небольшого корпуса и 300–1000 шагов, проверь, что процесс работает, затем увеличивай объём. Скрипт не требует CUDA. При наличии CUDA можно передать `--device cuda`.

## Формат данных

`data/instructions.jsonl` содержит учебные пары «вопрос по программированию — ответ с объяснением и кодом». Подготовить текстовый корпус можно командой:

```powershell
python ml/kolzailm/prepare_data.py
```

`train.txt`: UTF-8, сериализованные примеры. Текущий тренер всё ещё учится предсказывать следующий байт по всему тексту, включая формулировку вопроса; это ещё не полноценное instruction fine-tuning с маской потерь только на ответе. Используй собственные примеры и материалы с подходящими лицензиями. Не добавляй пароли, личные данные и приватную переписку.
